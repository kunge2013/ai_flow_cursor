# 组织器节点 (Organizer Node)

## 概述

组织器节点是一个用于数据整理、分类和组织任务的自定义节点。它可以帮助用户对输入的数据进行各种形式的整理操作。

## 功能特性

- **多种组织类型**: 支持分类、排序、分组、过滤、合并等多种整理方式
- **灵活的数据输入**: 支持直接输入数据或引用变量
- **自定义整理规则**: 可以定义具体的整理逻辑
- **多种输出格式**: 支持JSON、数组、对象、字符串等输出格式

## 节点属性

### 基本属性
- **节点名称**: 节点的显示名称
- **描述**: 节点的详细说明

### 组织器特有属性
- **组织类型**: 
  - `classify`: 分类整理
  - `sort`: 排序整理
  - `group`: 分组整理
  - `filter`: 过滤整理
  - `merge`: 合并整理

- **输入数据**: 要整理的数据或变量名
- **整理规则**: 定义具体的整理逻辑
- **输出变量**: 整理结果的变量名
- **输出格式**: 
  - `json`: JSON格式
  - `array`: 数组格式
  - `object`: 对象格式
  - `string`: 字符串格式

## 使用示例

### 1. 分类整理
```
输入数据: ["苹果", "香蕉", "橙子", "胡萝卜", "土豆"]
整理规则: 按水果和蔬菜分类
输出格式: JSON
```

### 2. 排序整理
```
输入数据: [3, 1, 4, 1, 5, 9, 2, 6]
整理规则: 按数值大小升序排列
输出格式: array
```

### 3. 分组整理
```
输入数据: [{"name": "张三", "age": 25}, {"name": "李四", "age": 30}, {"name": "王五", "age": 25}]
整理规则: 按年龄分组
输出格式: object
```

## 技术实现

### 节点模型 (OrganizerNodeModel)
- 继承自 `RectNodeModel`
- 设置节点尺寸: 160x60
- 定义左右锚点用于连接

### 节点视图 (OrganizerNode)
- 继承自 `RectNode`
- 紫色主题 (#9C27B0)
- 圆角矩形设计
- 包含图标和文本

### 属性组件 (OrganizerNodeProperties)
- Vue 3 Composition API
- Element Plus UI组件
- 响应式数据绑定
- 实时更新机制

## 集成方式

1. **节点注册**: 在 `nodes/index.ts` 中注册节点
2. **属性面板**: 在 `FlowEditor.vue` 中添加属性编辑支持
3. **拖拽支持**: 在逻辑节点分类中添加组织器节点
